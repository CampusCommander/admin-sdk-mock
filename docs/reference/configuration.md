# Configuration reference

This page lists every key of the configuration file.
The table comes from [schema/config.schema.json](../../schema/config.schema.json), and `npm run docs` regenerates it.
The [configuration guide](../guide/configuration.md) explains how the keys work together, with worked examples.

A key path joins nested keys with dots. `[]` stands for each item of a list.
A default of `required` means the key has no default and must appear.
The mock rejects every key that this table does not name.
